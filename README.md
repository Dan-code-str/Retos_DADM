## Notas

- Los retos 3 a 7 son versiones sucesivas del mismo juego de Triqui. Cada carpeta conserva el estado exacto de su entrega, tomado del historial de este repositorio.
- El Reto 0 se entregó originalmente en el repositorio [DADM_2026-2](https://github.com/Dan-code-str/DADM_2026-2). Aquí está la misma versión.
- Las claves de API no están en el repositorio:
  - El Reto 11 lee las claves de Gemini y Cloudflare de `local.properties`.
  - El Reto 12 necesita su propio `app/google-services.json`, descargado de la consola de Firebase.

  Cada README explica cómo configurarlos.
